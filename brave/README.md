# Dracula for Brave

This variant preserves the Chrome theme while improving contrast in Brave's
vertical tab strip. Brave renders inactive tab text at 70% opacity on the
toolbar color, so the Chrome variant's muted comment color is difficult to
read there. The Brave variant uses Dracula's foreground color for inactive tab
text, producing a contrast ratio of approximately 5.2:1.

## Install

1. Open `brave://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this `brave` directory.
5. Enable vertical tabs from `brave://settings/appearance`.
